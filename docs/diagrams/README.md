# Diagram index

Every Excalidraw whiteboard, rendered to PNG and embedded in the problem it belongs to.
Each diagram ships in three forms:

- `<name>.png` — what the docs embed.
- `excalidraw/<name>.excalidraw` — the scene file. Drag it into [excalidraw.com](https://excalidraw.com)
  to edit offline; this is the copy that survives if a share link ever expires.
- The share link in the table below — opens the original board.

*Frequency* is how often the problem has shown up, carried over from the source list.

The Job Scheduler board holds two passes at the problem, so it is rendered as two panels
(`job-scheduler-v1`, `job-scheduler-dag`); `excalidraw/job-scheduler.excalidraw` is the full board.

## Regenerating

The PNGs are rendered from the `.excalidraw` scenes with `@excalidraw/excalidraw`'s `exportToSvg`
(Excalifont subset embedded), then rasterised at 2× and quantised to 64 colours. Re-render by
importing the scene at [excalidraw.com](https://excalidraw.com) and exporting to PNG at 2×.
